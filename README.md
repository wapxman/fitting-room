# Примерочная 3D

Фигура в полный рост, которую можно крутить на 360° как в игре, и примерять на
неё одежду. Один файл `index.html` + `js/body.js`, Three.js с CDN, сборки нет.

## Что внутри

- **Настоящее 3D**, а не поворот картинки: орбита мышью/пальцем, колесо — зум,
  кнопки «Анфас / Профиль / Со спины», автоповорот.
- **Примерка**: верх, низ, обувь и верхняя одежда, у каждой вещи палитра из 16
  цветов. Одежда строится из ТЕХ ЖЕ профилей сечений, что и тело, с припуском —
  поэтому она садится по фигуре, а не висит рядом.
- **Три подложки** и кнопка снимка (PNG).
- **Перетащите `.glb`** в окно — покажу вашу настоящую 3D-модель вместо
  манекена, с автоматическим масштабом и постановкой на пол.

## Пропорции

Сняты с фронтального кадра скриптом `tools/analyze_photo.py`: сегментация фона
заливкой от углов, ширины торса по центральному отрезку строки (иначе в A-позе
меряется размах рук), уровни и цвета. Из замеров взяты ОТНОШЕНИЯ (талия/плечи
0,746, бёдра/плечи 0,734), абсолютные величины — анатомические: по одному
фронтальному кадру ширину плеч не снять, к корпусу прижаты руки.

## Чего эта штука не делает

Это манекен по вашим пропорциям, а не ваш фотореалистичный двойник: из одного
кадра настоящую 3D-модель человека не построить. Хотите своё лицо и тело —
прогоните исходный кадр через сервис photo→3D (Meshy, Tripo, Hunyuan3D), а
полученный `.glb` перетащите в окно.
